# 💻 Student Day - Web Programming

Repository ini berisi materi latihan dan template dasar pembuatan website menggunakan **HTML5** dan **Bootstrap 5** untuk kegiatan **Student Day Web Programming** di **SMA Plus PGRI Cibinong**.

---

## 📌 Tentang Student Day Web Programming

**Student Day** di SMA Plus PGRI Cibinong adalah program unggulan khusus di hari Sabtu yang dirancang sebagai wadah bagi siswa untuk menyalurkan bakat, minat, hobi, serta meningkatkan keterampilan vokasi di luar kegiatan belajar mengajar reguler.

Pada **Student Day Web Programming (WebPro)**, siswa mempelajari konsep dasar hingga teknik pembuatan website modern, meliputi:
- Pembuatan struktur & tampilan web (**HTML & CSS**)
- Responsiveness & Framework UI (**Bootstrap 5**)
- Pemrograman dasar kustom (**JavaScript**)
- Pengenalan Framework tingkat lanjut (**CodeIgniter & Laravel**)

---

## 🛠️ Teknologi & Resource yang Digunakan

- **HTML5** - Struktur utama halaman web.
- **Bootstrap v5.3** - Framework CSS melalui CDN untuk tata letak (*grid system*), navbar, carousel, card, dan komponen responsif lainnya.
- **Aset Lokal:**
  - Gambar logo (`images/logo.png`)
  - Gambar slider/carousel (`images/slide1.jpg`, `images/slide2.jpg`, `images/slide3.jpg`)
