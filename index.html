Web Programming

Web Programming adalah salah satu Student Day yang ada di SMA Plus PGRI Cibinong, pada StudentDay WebPro kita belajar tentang pembuatan website menggunakan bahasa pemrograman web seperti HTML, CSS, dan JavaScript. Mata kuliah ini bertujuan untuk memahami konsep dasar dan teknik pembuatan website yang memungkinkan pengguna dapat mengakses dan berinteraksi dengan situs web.

Dalam StudentDay WebPro, siswa akan mempelajari berbagai aspek pengembangan web, termasuk desain antarmuka pengguna (UI), pengalaman pengguna (UX), serta pemrograman sisi klien dan sisi server. Selain itu, siswa juga akan diajarkan tentang penggunaan framework dan pustaka populer yang digunakan dalam pengembangan web modern. Framework yang dipelajari antara lain Code Igniter dan Laravel.

Student Day

Student Day di SMA Plus PGRI Cibinong adalah program unggulan khusus di hari Sabtu yang dirancang sebagai wadah bagi siswa untuk menyalurkan bakat, minat, hobi, serta meningkatkan keterampilan vokasi di luar kegiatan belajar mengajar reguler Senin sampai Jumat.

Ada berbagai macam Student Day yang dapat diikuti oleh murid, salah satunya Web Programming.
